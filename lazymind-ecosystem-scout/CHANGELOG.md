## 2.0.0 — 2026-10-27

基于提供的四文件压缩包升级，保留 Skill 定位、十四类地图、GitHub 扫描规则、registry CLI、旧表和历史日志。没有引入泛化增长系统、外部发布器或生产 Core 改动。

- 原子领取同时保存初始 partial 检查点；新增有期限租约、心跳、令牌校验和旧写者拒绝。修复领取后无检查点崩溃无法续跑。
- 扫描逐页事务落盘；完成全部页才推进游标；搜索/快照不证明 live coverage。未完成 Issue 保留待办，删除待办需要独立处理结论。
- memory/coverage/cursor 深合并，数组并集；完整历史保留，防止部分写入抹掉嵌套事实、覆盖范围和待办。
- 数据目录改为便携 V2 独立默认路径；移除个人项目路径。旧格式数据库拒绝原地打开写入；迁移只新建副本。
- 按 GitHub 不变 ID 处理改名/别名；保留历史、机会当前视图与同轮去重。
- 新增统一来源 Schema、GitHub 只读 adapter、显式公开 Skill 目录清单 adapter；其他来源保留接口，不批量爬取。
- 能力事实分六类，包含版本、来源、核验日期、限制和可运行范围；单独校准 PR873 中的转换、失败、恢复、编辑与审批事实。
- 增加七类业务场景映射；A 技术适配、B 生态传播与用户价值独立计算。高 Star 不能补足低适配。
- 增加十项行动结果字段及证据校验；保留 Contributor 独立执行阶段，不包含求职功能或自动发帖。
- 原版 2 项基线测试通过；V2 当前 39 项测试通过。完成三个指定候选的真实、有界只读取证和 adapter 入库，推荐数为 0。

有意调整的写入协议：repo-put 需要有效 claim_token；它不能直接推进扫描游标。旧版高分/ready 记录不能凭原分数自动晋升为 V2 推荐。具体迁移见 MIGRATION.md。
